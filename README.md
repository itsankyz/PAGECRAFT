# PageCraft

A physical-feel digital workshop for PDF document artisans.

## Features
- Merge PDFs
- Extract Pages
- Watermark Stamp
- Image to PDF
- Password Lock
- AI Smart Formatting *(coming soon)*

## Tech Stack
- React 19 + TypeScript
- Vite + Tailwind CSS v4
- pdf-lib (client-side PDF processing)
- Vercel (hosting + serverless API)

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy

Deployed on Vercel. Add `GEMINI_API_KEY` in Vercel environment variables for AI features.
